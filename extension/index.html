Eventually

Load it yourself. Not in the Chrome Web Store yet. Download the zip, unzip it, and load the folder in Chrome.

Download the zip
  1. Download the zip.
  2. Unzip it. You want the folder that contains manifest.json.
  3. In Chrome, go to chrome://extensions (paste that in the address bar).
  4. Turn on Developer mode — top right.
  5. Click Load unpacked and pick that unzipped folder.

Chrome may warn you about developer mode when it restarts. That’s just Chrome being Chrome about unpacked extensions. Pin Eventually, then open x.com/i/bookmarks — the panel lives there.
